# Inspiration

Code in this repository ported from other projects, with the version it was taken from.

- `manf/src/lz4.rs`: the LZ4 block encoder and decoder of [lz4_flex](https://github.com/pseitz/lz4_flex) 0.14.0, commit `1bffdcbbf906a234b913937cb2f57c0245915038` (MIT).
- `manf/src/crc32.rs`: the slice-by-16 CRC-32 of [crc32fast](https://github.com/srijs/rust-crc32fast) 1.5.0, tag `v1.5.0` (MIT or Apache-2.0, taken under MIT).
- `manf/src/sha256.rs`: this repository's own `src/sha256.rs` at commit `2024691c0ac7e18eb72fe68d13e12d80c5ba997e`.
